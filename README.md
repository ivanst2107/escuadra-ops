# Escuadra Ops

Website for Escuadra Ops, S.A.S.: companies that run themselves, 90% of the way (scripts + AI).

- Stack: Vite, plain HTML/CSS/JS, ES/EN toggle (`src/main.js`).
- Deploy: push to `main` → GitHub Actions → GitHub Pages.
- Dev: `npm install && npm run dev`.
- Custom domain later: set `base: '/'` in `vite.config.js`, add `public/CNAME`, update the og URLs in `index.html`.
